# Linked Helper Personalization Concept

Portfolio concept based on a product marketing test assignment for Linked Helper Personalization Suite.

> **Concept project / test assignment. This is not an official Linked Helper production page and is not endorsed by Linked Helper.**

## Author / role

**Svetlana Chukova** — product marketing direction, scope control, review, QA, and final decisions.

Research organization, drafting, visual exploration, and front-end implementation were AI-assisted with ChatGPT. The workflow was iterative and evidence-based rather than a one-shot generation process.

**Portfolio:** https://gkkm8bm7rn-eng.github.io/portfolio/

## Project goal

Turn a completed product-marketing assignment into a working landing page and show the full path from research to implementation:

`Research → Positioning → Message House → Landing Architecture → Copy → Hero Concept → Front-end Build`

The project is intentionally presented as a portfolio case rather than as an imitation of an official production release.

## Source work

The concept is grounded in two completed deliverables:

- **Part 1** — semantic core, SERP intent, competitor analysis, Linked Helper and competitor Voice of Customer, Value Proposition Mapping, Message House, 16-block landing architecture, final landing copy, and SEO.
- **Part 2** — static Hero illustration brief built around `Prospect Context → Personalized Sequence → Review / Approve`, with Custom Variables from CSV and IF–THEN–ELSE fallback represented as the controlled personalization mode.

## Core positioning

**Personalization at scale + control over what gets sent.**

AI personalization is not treated as a standalone USP. The concept emphasizes the combination of:

- prospect-specific AI sequences;
- controlled message templates;
- Custom Variables imported from CSV;
- presence-based IF–THEN–ELSE fallbacks;
- review/edit/approval before sending;
- reply-aware campaign control.

## Landing architecture

The implementation follows the approved 16-block structure:

1. Hero
2. Social Proof Bar
3. Problem / Solution
4. AI Personalization
5. Rule-Based Personalization
6. Review & Reply Control
7. How It Works
8. Use Cases
9. Deep Social Proof
10. Operational Guardrails
11. Support
12. Related Features
13. Pricing
14. Educational Content
15. FAQ
16. Final CTA

## Hero concept

The primary product-led visual communicates one clear flow:

`Prospect Context → Personalized Sequence → Review / Approve`

A smaller secondary layer represents the controlled template workflow:

`Custom Variable from CSV → IF value → personalized fragment / ELSE → natural fallback`

No invented performance metrics, safety scores, autonomous AI sending, or unsupported interface states are used.

## Implementation

The current build is a dependency-free static front end:

- semantic HTML;
- responsive CSS;
- vanilla JavaScript;
- mobile navigation;
- accessible skip link and reduced-motion support;
- interactive Local / Cloud pricing switch;
- SEO title and meta description from the approved assignment;
- portfolio disclaimer and external links to official Linked Helper pages.

## Product-fact check

Before the visual refinement pass, key product and pricing details were re-checked against the current official Linked Helper Personalization Suite and pricing pages (September 2026). The portfolio concept remains grounded in the approved assignment while avoiding claims that are not supported by current product information.
