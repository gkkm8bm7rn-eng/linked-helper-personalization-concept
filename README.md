# Linked Helper Personalization Concept

Portfolio concept based on a product marketing test assignment for Linked Helper Personalization Suite.

> Concept project / test assignment. This is not an official Linked Helper production page.

## Project goal

Turn the completed product-marketing assignment into a working landing page that demonstrates the full path from research and positioning to page architecture, copy, interface concept, and implementation.

## Source work

The concept is grounded in two completed deliverables:

- Part 1: semantic core, competitor analysis, Voice of Customer, Value Proposition Mapping, Message House, 16-block landing architecture, final landing copy, and SEO.
- Part 2: static Hero illustration brief built around `Prospect Context → Personalized Sequence → Review / Approve`, with Custom Variables from CSV and IF–THEN–ELSE fallback as the controlled personalization mode.

## Positioning

**Personalization at scale + control over what gets sent.**

AI personalization is not treated as a standalone USP. The concept emphasizes the combination of prospect-specific AI sequences, rule-based personalization, missing-data handling, and pre-send review controls.
